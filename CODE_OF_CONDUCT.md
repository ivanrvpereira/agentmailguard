# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies in every project space: issues, pull requests, discussions, reviews, and any other place where you speak for the project.

## Report a problem

If someone breaks the code of conduct, report it privately to the maintainer, [@ivanrvpereira](https://github.com/ivanrvpereira).
Do not report it in a public issue.
You can also [report abuse to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
The maintainer reviews every report, keeps the reporter's identity private, and decides on the action as the Contributor Covenant's enforcement guidelines describe.
